Character Mod Exporter: exports the files PlayerSync applied to another character (ZoneSync, syncshell or pair)
into a folder you choose, with a manifest, a report and, when complete, a Penumbra package for manual import.

Requires the patched PlayerSync build with export IPC v1 (`PlayerSync-ExportIPC.zip`, unofficial, replaces
PlayerSync). It does not work with stock PlayerSync. Not tested in game yet; see docs/MANUAL_TEST_PLAN.md.
Installation: docs/INSTALL.md.
